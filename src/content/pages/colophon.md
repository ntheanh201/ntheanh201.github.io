This site is built with [Astro](https://astro.build) from plain Markdown files in git, and served as static HTML. There's no client framework. The only JavaScript is the theme toggle and the copy buttons on code blocks. Code is highlighted at build time with [Shiki](https://shiki.style).

From 2022 to 2026 the blog was written in Notion and published by a Go generator, a fork of [Krzysztof Kowalczyk's notion blog](https://github.com/kjk/blog). In October 2026 every post moved to Markdown, with the same URLs.

The blog is inspired by

- [Mark McGranaghan](https://markmcgranaghan.com/)
- [Krzysztof Kowalczyk](https://blog.kowalczyk.info/)

and I also want to thank

- [brandur.org, Brandur Leach](https://brandur.org/)

These blogs are where I learned how to create content and share knowledge.
