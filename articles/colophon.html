Colophon

This site is built with Astro from plain Markdown files in git, and served as static HTML. There’s no client framework. The only JavaScript is the theme toggle and the copy buttons on code blocks. Code is highlighted at build time with Shiki.

From 2022 to 2026 the blog was written in Notion and published by a Go generator, a fork of Krzysztof Kowalczyk’s notion blog. In October 2026 every post moved to Markdown, with the same URLs.
